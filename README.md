# PYTHON-PROJECT
A Python GUI application built using Tkinter to check whether a word is palindrome and whether two words or sentences are anagrams.


PALINDROME and ANAGRAM CHECKER

About the Project

This is a simple Python project that uses Tkinter to create a Graphical User Interface (GUI). It allows users to check whether a word or sentence is a palindrome or whether two words or sentences are anagrams.
A palindrome is a word or sentence that reads the same forward and backward, such as "madam".
An anagram is formed when two words contain the same letters in a different order, such as "listen" and "silent".

Features

- Simple and user-friendly graphical interface.
- Checks whether a word or sentence is a palindrome.
- Checks whether two words or sentences are anagrams.
- Displays results through the GUI.
- Handles user input.

Technologies Used

- Python
- Tkinter

Learning Outcomes

Through this project, I learned about Python functions, string manipulation, conditional statements, user input, and creating graphical interfaces using Tkinter.

Purpose

The purpose of this project is to apply basic Python programming concepts to develop a simple and interactive application.
